# Motor Barbara

Núcleo desacoplado de Mestre IA para RPG. Reconstrução 1.0 em andamento.

## Garantias do núcleo
- Mundo Vivo obrigatório e independente da câmera
- RAG com escopo por sistema/projeto/campanha e proveniência
- Rule Gate fail-closed
- memória estruturada e separação entre fato, rumor e inferência
- NPCs com conhecimento limitado e agendas privadas
- patches de estado validados
- idempotência, replay e recuperação transacional

> O branch `backup-xwn-pre-barbara` preserva o conteúdo XWN anterior ao corte.
